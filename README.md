# D435i_FoundationStereo

这个仓库提供了使用Intel RealSense D435i深度相机采集数据，为FoundationStereo准备输入数据的工具。

## 主要功能

### d435i.py
这个脚本是项目的核心，提供以下功能：

1. **相机配置和流设置**
   - 配置并启用左右红外流 (IR)，分辨率：1280x720，帧率：30fps
   - 配置并启用彩色流 (RGB)，分辨率：1280x720，帧率：30fps
   - 配置并启用深度流，分辨率：1280x720，帧率：30fps

2. **相机标定参数处理**
   - 自动获取左IR相机内参
   - 记录基线距离（左右IR相机间距：0.05米）
   - 生成并保存相机参数文件 `K.txt`
     - 第一行：展平的3×3内参矩阵
     - 第二行：基线距离

3. **图像处理**
   - 对左右IR图像进行畸变校正
   - 将灰度IR图像转换为RGB格式（为适配FoundationStereo要求）
   - 将深度图转换为伪彩色显示
   - 支持深度图与彩色图对齐

4. **实时预览与保存**
   - 实时显示四个窗口：
     - 彩色图像
     - 深度图（伪彩色）
     - 校正后的左IR图像
     - 校正后的右IR图像
   - 按'q'键保存所有图像

### 输出文件
所有输出文件保存在 `save1` 目录下：
- `rect_left.png`: 校正后的左IR图像（RGB格式）
- `rect_right.png`: 校正后的右IR图像（RGB格式）
- `color_image2.png`: 彩色图像
- `depth_image.png`: 深度图（伪彩色格式）
- `K.txt`: 相机参数文件

### point_dis.py
用于计算两点之间的欧氏距离的辅助脚本：
- 支持2D和3D点的距离计算
- 使用numpy进行高效计算
- 输出精确到小数点后6位的距离结果

## 使用方法

1. 确保已安装依赖：
   ```
   pip install pyrealsense2 numpy opencv-python
   ```

2. 连接D435i相机

3. 运行数据采集脚本：
   ```
   python d435i.py
   ```

4. 在预览窗口中确认图像质量，按'q'键保存当前帧的所有图像

## FoundationStereo使用说明

采集到的图像可直接用于FoundationStereo：
- 使用 `rect_left.png` 和 `rect_right.png` 作为输入的双目图像对
- 使用生成的 `K.txt` 作为相机参数文件

## 注意事项

- 确保相机固定稳定，避免运行时移动
- 采集时确保场景光照充足
- 确保图像清晰无模糊后再保存
- 所有图像均以无损PNG格式保存
